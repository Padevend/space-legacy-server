# Operations Runbook — SPACE LEGACY Server

## 1. Environment & Architecture Overview

SPACE LEGACY is an isolated, modular monolith built on **Node.js 20+**, **Hono**, **Prisma ORM**, and **PostgreSQL 16**.
It exposes:
- Public educational API (`/api/v1`)
- Mission Control back-office single-page app (`/admin`)
- Administrative endpoints (`/api/v1/admin/*`)
- Health probes (`/health/live`, `/health/ready`)

## 3. Routine Operations & Commands

### 3.1 Initial Setup
```bash
# Install dependencies
pnpm install

# Setup environment
cp .env.example .env

# Run database migrations
pnpm db:migrate

# Seed authentic Moon & Mars reference dataset
pnpm db:seed
```

### 3.2 Starting the Platform
```bash
# Development mode with live reload
pnpm dev

# Production build and run
pnpm build
pnpm start
```

### 3.3 Database Reset & Cold Reseeding
When developing or validating migrations:
```bash
# Resets all tables and executes full seed cold
pnpm db:reset
```

### 3.4 Creating an Administrator Account
To bootstrap an admin user for back-office access:
```bash
pnpm admin:create
```
Default administrator credentials generated by the seed:
- **Email:** `admin@spacelegacy.test`
- **Password:** `AdminSpaceLegacy2026!`
- **Role:** `ADMIN`

### 3.5 Bulk Data Ingestion (CLI & API)
- **API Endpoint:** `POST /api/v1/admin/ingestion` (and `POST /api/v1/admin/ingestion/validate` for dry runs).
- **CLI Ingest Command:**
  ```bash
  pnpm ace ingest:bulk path/to/bundle.zip
  ```

## 4. Verification & Quality Gates

Run the single mandatory verification command:
```bash
pnpm verify
```
This automatically verifies:
1. Prisma schema validity (`prisma validate`)
2. TypeScript strict type-checking (`tsc --noEmit`)
3. ESLint style & architecture boundary enforcement (`pnpm lint`)
4. Prettier formatting consistency (`pnpm format:check`)
5. Full Vitest automated test suite (`pnpm test` — 23 test suites, 165+ tests)
6. Anti-drift synchronization between routing and documentation (`pnpm test:drift`)
7. High-severity dependency vulnerability audit (`pnpm audit --audit-level=high`)
8. TypeScript production compilation (`pnpm build`)
