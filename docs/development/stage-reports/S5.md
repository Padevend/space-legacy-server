# Stage 5: Editorial — Exit Gate Report

## 1. Scope & Objective
Implement the 2 editorial domain modules delivering educational stories and multimedia assets about historical NASA equipment left behind in space:
- `media`: Multi-type digital assets (photographs, 3D reconstructions, audio recordings, video footage, scientific documents, animations).
- `stories`: Curated narrative content, historical chronicles, and technical deep dives with publication workflows.

Key requirements:
1. **Mandatory AI Provenance Tracking**: Serializer deterministically computes `requiresAiLabel: true` when `provenanceType === 'AI_GENERATED_ILLUSTRATION'` (and `false` otherwise) so frontend clients can display the mandatory AI notice.
2. **Zero-Leakage Public Visibility Rule**: Unpublished stories (`DRAFT`, `REVIEW`, `ARCHIVED`) are strictly concealed from anonymous public endpoints. Lookups for unpublished story slugs/UUIDs return a clean `404 NOT_FOUND` to prevent leaking editorial existence.
3. **Editorial State Machine**: Publication state transitions (`POST /api/v1/admin/stories/:id/transitions`) strictly enforce valid lifecycle paths:
   - `DRAFT` -> `REVIEW`, `ARCHIVED`
   - `REVIEW` -> `DRAFT`, `PUBLISHED`, `ARCHIVED`
   - `PUBLISHED` -> `ARCHIVED`, `DRAFT`
   - `ARCHIVED` -> `DRAFT`
   Invalid transitions (e.g. attempting to skip review directly to `PUBLISHED`) are rejected with `409 CONFLICT`.
4. **Automated Publication Timestamps**: Transitioning a story to `PUBLISHED` automatically records `publishedAt = new Date()`. Newly created stories start in `DRAFT` with `publishedAt = null`.
5. **XSS Stripping**: HTML tags and malicious scripts in story `title`, `hook`, `content`, and media captions are stripped via plain-text sanitization.
6. **Join Table Management**: Standardized relation endpoints for all join tables:
   - Media: `EquipmentMedia` (`PUT`/`DELETE /api/v1/admin/media/:id/equipment/:equipmentId`).
   - Stories: `StoryMission`, `StoryEquipment`, `StoryEvent`, `StoryMedia`, `StorySource`.
7. **Documentation Deliverables**: Standalone typed entities in `docs/entities/media/` and `docs/entities/story/`, updated barrel export `docs/entities/index.ts`, endpoint docs `docs/api/endpoints/{media,stories}.md`, `ADR-007-editorial-workflow-and-media.md`, real JSON examples captured from e2e tests, anti-drift contract tests, and route registry updated (127 routes).

## 3. Security Checks & Hardening
- **Mandatory AI Notice**: Media assets with `AI_GENERATED_ILLUSTRATION` provenance return `requiresAiLabel: true`, satisfying competition and ethical standards.
- **Unpublished Editorial Concealment**: Public endpoints strictly enforce `where: { publicationStatus: 'PUBLISHED' }`. Draft and archived stories return a generic `404 NOT_FOUND` with no detail leakage.
- **Transition Workflow Integrity**: Status transitions cannot be forged via standard `PATCH` updates; they must invoke the transition endpoint and conform to the transition state machine.
- **XSS Stripping**: HTML tags (`<script>`, `<iframe>`, `<img>` with `onerror`) are completely stripped from story titles, hooks, content, and media captions before database storage.
- **Role-Based Access Control**:
  - Content creation, updates, and relation linking permitted to `EDITOR` and `ADMIN`.
  - Content deletion strictly restricted to `ADMIN` (returns `403 FORBIDDEN` for `EDITOR`).

## 4. Problems Encountered & Resolutions
1. **`Prisma.AuditLog` JSON Typing**:
   - *Problem*: Passing `string | null` to `diffSummary` raised TypeScript error `TS2322: Type 'string | null' is not assignable to type 'InputJsonValue | NullableJsonNullValueInput'`.
   - *Fix*: Aligned `diffSummary?: Prisma.InputJsonValue | undefined` in `media.repository.ts` and `stories.repository.ts`, passing structured JSON objects directly.
2. **`publishedAt` Date Typing in Service**:
   - *Problem*: `updateData.publishedAt` typed as `string | Date | ...` raised `TS2551` when calling `.toISOString()` directly.
   - *Fix*: Extracted explicit `publishedAtDate = targetStatus === 'PUBLISHED' ? new Date() : undefined` and formatted cleanly for the audit summary.
