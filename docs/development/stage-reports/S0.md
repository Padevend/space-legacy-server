# Stage S0: Isolated AdonisJS v6 MVC Modules Refoundation — Exit Gate Report

## 1. Scope & Objective
Refound the SPACE LEGACY backend according to the **v3 Refoundation Brief**:
- Adopt an **AdonisJS v6-style project structure organized as isolated MVC modules** on top of Hono.
- Establish strict role-folder purity per module: `controllers/`, `models/`, `repositories/`, `services/`, `validators/`, `serializers/`, `policies/`, `exceptions/`, `routes/`, `providers/`.
- Guarantee **absolute module isolation**: zero cross-module imports, zero runtime calls across modules, zero querying of another module's Prisma delegates.
- Dedicate multi-module reading exclusively to query modules (`catalog` for public read models, `dashboard` for admin metrics).
- Merge `users` into `auth`.
- Quarantine non-essential MVP features in `legacy/` with isolation enforcement.
- Eliminate the legacy `src/` hierarchy completely with subpath imports (`#modules/*`, `#infrastructure/*`, `#contracts/*`, etc.).
- Verify end-to-end against real PostgreSQL 16 on port 5433 with 100% test pass rate and zero documentation drift.

## 2. Actions & Artifacts Built

### 2.1 Isolated MVC Modules (`app/modules/`)
Each domain capability is now an isolated MVC slice:
- **`app/modules/archives`**: Internal scraped data traceability (`Archive`, `ArchiveMission`, `ArchiveEquipment`, `ArchiveEvent`, `ArchiveSource`).
- **`app/modules/audit`**: Read-only administrative audit log ledger (`AuditLog`).
- **`app/modules/auth`**: User identity, Argon2id passwords, JWT access & refresh tokens, account lockout brute-force defense, and Admin User management (`User`, `RefreshToken`).
- **`app/modules/catalog`**: Cross-domain public read models (`/home`, `/destinations`, `/explore`).
- **`app/modules/celestial_bodies`**: Reference celestial bodies (`CelestialBody`).
- **`app/modules/dashboard`**: Administrative metrics aggregation (`/admin/dashboard/counters`).
- **`app/modules/equipment`**: Equipment hierarchy, cycle prevention, multi-join relations (`Equipment`, `EquipmentLocation`, `EquipmentPerson`, `EquipmentSource`, `EquipmentMedia`).
- **`app/modules/events`**: Historical milestones and join records (`Event`, `EventEquipment`, `EventLocation`, `EventPerson`, `EventSource`).
- **`app/modules/health`**: Production liveness (`/health/live`) and database readiness probes (`/health/ready`).
- **`app/modules/ingestion`**: Safe batch ingestion and tracking of data processing bundles (`IngestionRun`).
- **`app/modules/locations`**: Landing sites, surface features, and coordinates (`Location`).
- **`app/modules/measurements`**: Scientific data preserving 8-decimal string precision (`Measurement`, `MeasurementSource`).
- **`app/modules/media`**: Educational assets with mandatory AI provenance labeling (`Media`).
- **`app/modules/missions`**: Space programs and expedition records (`Mission`, `MissionEquipment`, `MissionPerson`, `MissionSource`).
- **`app/modules/people`**: Astronauts, scientists, and mission personnel (`Person`).
- **`app/modules/sources`**: NASA citations and URL verification (`Source`).
- **`app/modules/stories`**: Curated editorial state machine (Draft -> Review -> Published -> Archived) and relations (`Story`, `StoryMission`, `StoryEquipment`, `StoryEvent`, `StoryMedia`, `StorySource`).

### 2.2 Framework Primitives (`app/infrastructure/`, `app/middleware/`, `app/exceptions/`)
- **`app/infrastructure/container/`**: Scoped dependency injection container supporting request-scoped lifetimes and module providers.
- **`app/infrastructure/database/`**: Prisma 7 Client instantiation via `@prisma/adapter-pg` and transaction runners.
- **`app/infrastructure/http/`**: OpenAPI factory, typed HTTP context, pagination & sort query parsers, standardized response envelopes (`ok`, `created`, `paginated`, `noContent`).
- **`app/infrastructure/logger/`**: Production Pino structured JSON logger with security redaction.
- **`app/infrastructure/rate_limit/`**: Sliding-window rate limiter with memory and Redis adapters.
- **`app/infrastructure/security/`**: Argon2id password hasher, jose JWT token service, SSRF `safeFetch` guard, trusted proxy resolver, URL validator, plain-text sanitizer.
- **`app/middleware/`**: 13-stage security kernel (request ID, trusted proxy, secure headers, CORS, timeout, body limit, content-type guard, rate limit, CSRF guard, auth, ability RBAC, request logging).
- **`app/exceptions/`**: Centralized `AppException` catalog, Prisma error mapper, Zod error mapper, global HTTP error handler.

### 2.3 Quarantine (`legacy/`)
Non-essential features parked outside the runtime pipeline:
- `legacy/social/`: Public forum, visitor comments, messaging.
- `legacy/scoring/`: Quiz and gamification engines.
- `legacy/cartography/`: 3D map rendering and interactive coordinates canvas.
- `legacy/ai_agent/`: Asynchronous prompt generation tasks and workers.
- `legacy/storage/`: Direct file upload adapters.
