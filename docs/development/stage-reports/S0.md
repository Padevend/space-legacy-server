# Stage 0: Foundations — Exit Gate Report

## 1. Scope & Objective
Establish the foundational infrastructure of the SPACE LEGACY backend:
- Project repository setup with strict TypeScript, ESLint, Prettier, and Vitest.
- Correct the two fatal Prisma schema bugs in the original specification (`MediaProvenance` enum mapping and `EquipmentLocation` surrogate key).
- Add additive models (`User`, `RefreshToken`, `AuditLog`, `IngestionRun`).
- Configure typed environment validation (`start/env.ts`) and typed configuration modules (`config/*`).
- Configure Pino structured logging with production-safe redaction.
- Implement unified error catalog (`AppException`), Prisma and Zod error mappers, and global HTTP error handling.
- Build request ID middleware, secure headers, and liveness/readiness health probes (`/health/live`, `/health/ready`).
- Create initial committed migration (`20261114231005_init`) and fake-marked seed (`prisma/seed.ts`).
- Verify against real PostgreSQL 16 container on port 5433.
- Establish documentation deliverable skeleton and verify `pnpm verify` exit gate.

## 2. Actions & Artifacts Built
- **Environment & Config**:
  - `start/env.ts`: Zod-validated environment rejecting boot on invalid configs or weak production secrets.
  - `config/`: App, database, logger, security, cors, rate-limit, auth, ingestion configurations.
- **Database Layer**:
  - `prisma/schema.prisma`: Corrected `RECONSTRUCTION_3D @map("3D_RECONSTRUCTION")`, `equipmentLocationId` surrogate key on `EquipmentLocation`, additive models `User`, `RefreshToken`, `AuditLog`, `IngestionRun`, and `@@unique([url])` on `Source`.
  - `prisma.config.ts`: Prisma 7 configuration file with `@prisma/config`.
  - `prisma/migrations/20261114231005_init/migration.sql`: Committed initial migration deployed via `prisma migrate deploy`.
  - `prisma/seed.ts`: Seed script provisioning fake-marked test accounts and celestial bodies.
- **Framework & HTTP Layer**:
  - `src/core/http/`: Context types, response envelope helpers (`ok`, `created`, `paginated`, `noContent`), pagination & sort parsers, application factory (`createApp`).
  - `src/core/exceptions/`: `AppException`, unified error codes, global error handler, Prisma and Zod error mappers.
  - `src/core/logger/`: Pino logger with redaction, format switching, and request duration logger.
  - `src/core/security/`: Request ID, trusted proxy resolution, secure headers, CORS, timeout, body limit, content-type guard, in-memory rate limiter, CSRF guard, sanitization, URL validator, password hashing (Argon2id), tokens (jose), and `safeFetch`.
  - `src/modules/health/`: Full modular implementation of health probes following the layering rule (`routes` -> `controller` -> `service` -> `repository`).
  - `start/kernel.ts`: The 13-stage middleware pipeline.
  - `start/routes.ts`: Central routing table.
  - `bin/server.ts`: Server entry with graceful shutdown.
  - `bin/console.ts`: Ace-style CLI runner.
  - `commands/`: `routes-list`, `docs-generate`, and stubs.
