# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `1.x` | :white_check_mark: |
| `< 1.0` | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in the SPACE LEGACY backend, please do not disclose it publicly or open a public issue.

Submit a confidential security report via GitHub Security Advisories or contact the repository maintainers. Reports will be acknowledged within 48 hours with a coordinated disclosure timeline.
