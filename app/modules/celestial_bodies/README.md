# Celestial Bodies Module

## Purpose
Manages planetary and stellar bodies (stars, planets, moons, asteroids) that serve as destinations or parent bodies for landing and impact locations.

## Owned Models
- `CelestialBody`

## Endpoints
### Public
- `GET /api/v1/celestial-bodies`
- `GET /api/v1/celestial-bodies/:id`

### Admin
- `POST /api/v1/admin/celestial-bodies`
- `PUT /api/v1/admin/celestial-bodies/:id`
- `DELETE /api/v1/admin/celestial-bodies/:id`
