# People Module

## Purpose
Manages astronauts, flight directors, engineers, scientists, and historical contributors associated with space missions and equipment.

## Owned Models
- `Person`

## Endpoints
### Public
- `GET /api/v1/people`
- `GET /api/v1/people/:id`

### Admin
- `POST /api/v1/admin/people`
- `PUT /api/v1/admin/people/:id`
- `DELETE /api/v1/admin/people/:id`
